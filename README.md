# Cyber Security Course · مساق الأمن السيبراني

تطبيقٌ تفاعليّ ثنائي اللغة (عربي/إنجليزي) يعمل بلا إنترنت — إحدى عشرة وحدة، مختبراتٌ حيّة، بطاقات مذاكرة، واختبارات. **قابلٌ للتثبيت على الجوّال** (PWA).

**الرابط الحيّ:** https://aabdalaal.github.io/cybersecurity-course/

## بنية المجلّد
- `index.html` — التطبيق كاملاً.
- `manifest.webmanifest` — بيانات التطبيق للتثبيت (الاسم، الأيقونات، الألوان، وضع standalone).
- `sw.js` — Service Worker للعمل دون إنترنت بعد أوّل فتح.
- `icon-192.png` · `icon-512.png` · `icon-maskable-512.png` · `icon-180.png` · `icon.svg` — أيقونات التطبيق.
- `.nojekyll` — يمنع معالجة GitHub Pages التلقائية.
- `qr/` — رموز QR للمختبرات.
- `docs/` — التعليمات ودليل الرفع على GitHub.

## التثبيت على شاشة الجوّال (Add to Home Screen)
افتح الرابط الحيّ في متصفّح الجوّال ثمّ:
- **iPhone / iPad (Safari):** زرّ المشاركة ⬆️ → «إضافة إلى الشاشة الرئيسية» (Add to Home Screen) → إضافة.
- **Android (Chrome):** قائمة ⋮ → «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
تظهر الأيقونة كتطبيقٍ مستقلّ، ويفتح ملء الشاشة ويعمل دون إنترنت بعد أوّل تحميل.

> ملاحظة: ميزة التثبيت تعمل من الرابط المستضاف (HTTPS)، لا من الملفّ المفرد المفتوح محلياً.

## النشر على GitHub Pages
1. ارفع محتوى هذا المجلّد إلى المستودع (انظر `docs/رفع-على-GitHub-من-VSCode.md`).
2. Settings → Pages → Branch: `main` / `root` → Save.

## الربط العميق (لرموز QR)
`.../#u=4` وحدة · `.../#u=4&tab=lab` مختبر · `.../#u=7&tab=quiz` اختبار — `u` من 1 إلى 11.
