# Cyber Security Course · مساق الأمن السيبراني

تطبيقٌ تفاعليّ ثنائي اللغة (عربي/إنجليزي) يعمل بلا إنترنت بعد أوّل فتح — إحدى عشرة وحدة، مختبراتٌ حيّة، اختبارات، وتحفيز.

النشر على GitHub Pages
الربط العميق (Deep links) — لرموز QR في الكتاب
- الرئيسية: `.../` 
- وحدةٌ بعينها: `.../#u=4` (الوحدة الرابعة)
- مختبر وحدةٍ مباشرةً: `.../#u=4&tab=lab`
- اختبار وحدة: `.../#u=7&tab=quiz`

`u` من 1 إلى 11 · `tab` = `concept` | `lab` | `quiz`

## ثبات الروابط (مهمّ لرموز QR المطبوعة)
لا تُرمّز رابط `github.io` مباشرةً في الكتاب. استعمل رابطاً وسيطاً تملكه (نطاق مختصر أو تحويل)
يشير إلى الاستضافة — فإن نقلتَها لاحقاً تبقى الرموز المطبوعة صالحة.
